# Keep the Product SEO contract simple and delete discontinued products

Dongphugia will model public catalogue commerce with only `PUBLIC_PRICE` or `CONTACT_FOR_QUOTE` and `IN_STOCK` or `OUT_OF_STOCK`; it will not infer discontinuation from a missing price or build a lifecycle state machine, Merchant workflow, preorder/backorder flow, or retained legacy-product system before those capabilities are required. Confirmed discontinued products are deleted through a separate catalogue process, their old URLs return 404 by default, and a 301 is created only for a manually verified equivalent replacement; order lines retain immutable snapshots so deletion cannot rewrite history. Structured data, UI, cart, and order pricing use the same price projection, and quote-only products do not fabricate Product offers, ratings, identifiers, availability, or expiry dates. This keeps customer operation understandable while preserving a clear future data contract without requiring the Issue #42 compatibility work to migrate production data.
