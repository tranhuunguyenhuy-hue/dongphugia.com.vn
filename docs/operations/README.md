# Release operations

Thư mục này là điểm bắt đầu cho mọi agent tham gia release, migration hoặc
vận hành production của Đông Phú Gia.

Đọc theo thứ tự:

1. [Agent hand-off standard](AGENT-HANDOFF-STANDARD.md)
2. [Agent hand-off template](AGENT-HANDOFF-TEMPLATE.md)
3. [Repository hygiene](REPOSITORY-HYGIENE.md)
4. [Cleanup hand-off 2026-08-01](CLEANUP-HANDOFF-2026-08-01.md)
5. Inventory mới nhất trong thư mục này
6. Hand-off hiện hành do mutation coordinator cung cấp

Tài liệu ở đây quy định cách bàn giao và quản lý repository. Nó không tự động
thay thế evidence runtime mới hơn. Nếu commit, digest, deployment hoặc DNS đã
thay đổi, agent phải ghi lại evidence exact mới trước khi hành động.
