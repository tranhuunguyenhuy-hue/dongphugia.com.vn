# Historical archive

Files in this directory preserve legacy decisions, authorship and implementation
history. They are non-authoritative for current execution. References to former
tools, assistants, roles, domains or hosting models describe their historical
context only; none of them owns or coordinates current work.

Current Codex sessions must start from the repository root `AGENTS.md`, then
read `docs/operations/MIGRATION-CHARTER.md` and
`docs/operations/CODEX-CONTEXT.md`. If an archived statement conflicts with
those sources or newly verified evidence, ignore the archived statement.
